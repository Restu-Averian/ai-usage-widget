# 10 — UI Acceptance Criteria

- [ ] Only Codex and Antigravity tabs appear.
- [ ] The application always uses fixed dark styling.
- [ ] A source value of 45% used displays as 55% remaining.
- [ ] Popup and tray menu show the same remaining value.
- [ ] Unknown displays as `—`.
- [ ] Connection, cached, stale, refreshing, and error states are understandable.
- [ ] No historical chart or screen appears.
- [ ] No compact-mode or appearance controls appear.
- [ ] Development mock controls are absent from production.
- [ ] Keyboard and screen-reader behavior passes.
