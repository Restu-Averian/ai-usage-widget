# 09 — Platform and Responsive Behavior

## macOS

- Behaves as a Menu Bar utility.
- Popup positions near the tray item when possible.
- Closing or hiding the popup does not quit the process.

## Windows

- Behaves as a System Tray utility.
- Popup remains within the active work area.
- Native context menu and Quit behave consistently.

The UI is one constrained desktop popup, not a responsive mobile application.
