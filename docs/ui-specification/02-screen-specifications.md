# 02 — Screen Specifications

## Main popup

Order:

1. app/provider header;
2. Codex and Antigravity tabs;
3. connection/freshness state;
4. remaining-quota ring;
5. quota period and reset time;
6. last refreshed state and refresh action;
7. settings entry.

The screen contains no historical chart.

## Settings

- Refresh interval.
- Launch at login.
- Connect, reconnect, disconnect, or open official dashboard when supported.
- Development mock controls are never shown in production.
