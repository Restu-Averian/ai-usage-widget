# 07 — Content and Copy

Canonical quota copy:

```text
55%
Remaining weekly
```

Tray copy:

```text
Codex — 55% remaining
Antigravity — Not connected
```

Unknown:

```text
—
Remaining weekly
```

Use `Used` only in internal technical explanations of source data, never as the primary user-facing metric.

Prefer short status copy: `Connected`, `Cached`, `Refreshing`, `Reconnect required`, `Provider unavailable`.
