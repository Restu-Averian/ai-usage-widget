# 06 — Interactions and Motion

- Left-click tray: toggle popup.
- Right-click tray: native menu.
- Escape or focus loss: hide popup where platform behavior permits.
- Refresh: keep prior value visible and indicate progress.
- Provider tab switch: immediate, no heavy animation.
- Dialogs: short fade/scale only when motion preference allows.

Motion must not delay access to quota information. No chart animation exists.
