# ADR 0006 — Simplify Product Scope to Codex and Antigravity

**Status:** Accepted  
**Date:** 2026-07-19

The active product contains only Codex and Antigravity. Historical usage, a third provider, compact mode, appearance selection, API dashboards, and mobile sync are removed.

The UI uses one fixed dark theme. The roadmap ends at M7 release hardening.
